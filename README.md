# 오렌지 심장 건강 실습실

「나는 오렌지로 데이터 분석한다」 3장 「내 심장은 건강할까?」를 웹 브라우저에서 따라 해 볼 수 있는 오렌지3 시뮬레이터입니다. 설치 없이 바로 사용할 수 있습니다.

**바로 사용하기:** https://cs196083.github.io/orange-heart-sim/

## 구성
- **워크플로 실습**: File(형식·역할 변경) → Box Plot(이상치 찾기·삭제·Reload) → Neural Network / Logistic Regression / Naive Bayes → Test and Score → ROC Analysis / Confusion Matrix → Predictions(테스트 데이터 12명). 미션 11개가 자동으로 체크됩니다.
- **위젯 도감**: 위젯 12종의 역할, 입출력, 주요 설정, 실습 포인트, 자주 하는 실수
- **나이브 베이즈 실험실**: 환자 정보를 하나씩 반영하며 사후 확률이 바뀌는 과정과 베이즈 정리 계산기
- **확인 퀴즈**: 12문항

데이터: Heart Attack Analysis & Prediction Dataset (heart.csv, 303명)
